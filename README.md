# Social Profile

A modern Flutter application for viewing and managing connected social media profiles, featuring Instagram and Facebook integrations.

## Features

- **Profile Dashboard:** A clean, responsive dashboard displaying the user's primary information.
- **Social Linking:** Dedicated sections for viewing linked Instagram and Facebook IDs.
- **Cross-Platform:** Built with Flutter to run seamlessly on iOS, Android, Web, and Desktop.
- **Responsive Design:** Adapts smoothly from narrow mobile screens to wide desktop displays.

## Setup

1. Ensure Flutter is installed on your machine.
2. Run `flutter pub get` to fetch dependencies.
3. Run `flutter run` to launch the app on your preferred device or emulator.
